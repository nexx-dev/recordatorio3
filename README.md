# Mi dúo favorito eres tú 💙

Una página romántica de dos pantallas, hecha con HTML, CSS y JavaScript vanilla y pensada primero para móviles.

## Cómo verla
1. Descarga y descomprime `mi_nina_web.zip`.
2. Abre `index.html` en tu navegador.
3. Para compartirla por internet, sube los tres archivos (`index.html`, `styles.css`, `script.js`) a un hosting estático como GitHub Pages, Netlify o Cloudflare Pages.

## Archivos
- `index.html`: estructura y textos.
- `styles.css`: diseño responsive, animaciones e ilustraciones CSS.
- `script.js`: navegación, tarjetas revelables, corazones animados y mini botón sorpresa.

## Personalización rápida
Puedes editar los textos directamente en `index.html`. Las respuestas del botón “Activar plan” están en el arreglo `plans` de `script.js`.

## Notas
- No requiere instalación ni framework.
- Google Fonts requiere conexión a internet; si no hay conexión, se usarán fuentes de respaldo.
- Las ilustraciones son CSS/emoji originales y decorativas; no incluye recursos oficiales de Call of Duty: Mobile o Bluey.
